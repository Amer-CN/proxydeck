CommandCode 代理控制台 v2.0（WebView2 独立程序版）
=================================================

【首次使用】
1. 直接双击 ProxyDeck.exe 打开控制台（发布包自带，无需构建）。
2. 双击 ProxyDeck.exe 打开控制台，点击左侧「能量核心」点火。
3. 在你的 Agent / 客户端里配置：
     Base URL: http://127.0.0.1:55990/v1
     API Key : 你在 commandcode.ai/studio 生成的 Key

【界面速览】
- 能量核心：点击点火 / 停堆（快捷键：空格）
- 链路配置：Base URL 一键复制；API Key 可选，点火时自动记住
- 链路监测：本地真实流经 token 统计（总消耗 / 今日 / 次数 / 分模型条形图）
- 模型矩阵：18 个模型按厂商分组，点击即复制模型名
- 运行日志：启停与错误事件流；「开机自启」开关在日志区右上角

【文件说明】
ProxyDeck.exe ... 主程序（控制台 + 代理核心一体）
api-key.txt ................ 记住的 API Key（可选功能，勿泄露）
stats.json ................. 本地使用统计
启动代理.bat / 停止代理.bat  命令行启停（无窗口后台模式）
设置/取消开机自启.bat ...... 登录 Windows 自动后台运行
（本工具为发布包直接可用，无需构建）

【注意】
- 仅支持 Windows；界面依赖系统自带的 WebView2 运行时（一般已随系统/Edge 预装）。
- 未签名开源程序，SmartScreen / 杀软首次提示选「仍要运行 / 允许」。
- 本工具只是接口转换，需自备 CommandCode 套餐（普通套餐即可）。
- 平时挂着即可（内存约 30MB）；随时可停堆，不影响数据，重新点火即恢复。

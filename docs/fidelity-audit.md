## 一、吵起来的时候听谁的（证据效力排序）

| 顺位 | 证据 | 为什么 |
|---|---|---|
| 1 | **原版 `index.html` 的 DOM 渲染事实** | 元素在不在，只看原版页面上有没有这个节点。样式表存在 ≠ 官方在用（见 fx-ramp 案）。 |
| 2 | **原版 `fx-fax.js` 的常量**（时间轴/音效编排/相位机） | 动画速度的唯一合法来源是其中的毫秒常量；「感觉差不多」「为了等响应拉一下」都不算数。 |
| 3 | **同视口截图逐像素比对** | CSS 同值 ≠ 渲染一致；最终要截图说话，且两边必须同浏览器、同视口、同裁剪区域。 |
| 4 | 几何量取（getBoundingClientRect / ComputedStyle） | 做门槛用（宽高超差就驳回），不能单独定案。 |
| 5 | grep / 文本计数 / 任何机器扫描 | 只做辅助。会骗人，见下。 |

**会骗人的证据（血泪清单）**：

1. **样式表扫描会撒谎**——`.fx-ramp`「台面斜坡」案：panel.css:1500 有完整样式（含专用色令牌 :1136），但 index.html 全文 grep `ramp` 零命中，且 .fx-controls 的官方注释明写「键行下移（**灰线删除后**占位还原）」（panel.css:1497）——官方作者删掉了这根线，只留死 CSS。照样式表把它复活 = 造假。
2. **注释里的字样会虚报**——「查看详情」曾在全文 grep 出 3 处命中，全在 `<!-- -->` / `/* */` 注释里，页面可见文本为零。文本断言必须排除注释或直接量渲染树。
3. **数值区间断言会放过难看的**——机身高度落进 [768,800] 不代表复刻成功：第 4 轮 784 达标但纸上内容全是自编的。数字过门槛后必须看截图。
4. **事件驱动的动画时间轴会全盘错位**——把「传送段」改成等后端响应（真实 1-2 分钟、DEMO 假响应 8s），原版是固定 3200ms 假进度（fx-fax.js:327）。传送段一拖，回执、撕纸、换纸的音画全部失去与官方对齐的意义。动画速度只允许来自 fx-fax.js 常量。
5. **取证脚本自身会错**——URL 根目录不对导致整页 404 还全绿；没开 `Runtime.enable` 导致表达式返回 undefined；`returnByValue` 拿不到闭包内变量。脚本 FAIL 先怀疑脚本，再怀疑页面。
6. **结论**：数字断言只做门槛，**裁决看同视口截图对比**；「官方」的认定需要 index.html DOM + fx-fax.js 常量 + 截图三源一致。

## 三、官方没有、不许照抄/不许复活的清单

1. **`.fx-ramp` 台面斜坡（那根灰线）**：CSS 在（panel.css:1500）、DOM 不在（index.html 零命中）、官方注释证实已删。**机器里不许出现这个元素。**
2. **原版 demo 页的脚手架**——不算传真机的一部分，复刻时禁止带上：index.html:12-23 的 `<header class="pt-page-head">`（页面顶行标题 + 主题切换按钮 ptThemeBtn「暗色」+ 语言切换）。传真机的参照范围 = `#feedback-fx` 区块（index.html:532-663）+ fx-fax.js + panel.css 的 .fx-* 段与令牌，**不含页面顶栏**。
3. **我方历轮自创、复刻阶段禁入机器**（适配留待后端接线轮再做，且到时候只许换内容不许改结构）：overlay 顶部黑读数条（已删）、纸面渠道/模型下拉、机器进纸口行里的档案丝印按钮、回执四色判定章（fx-vstamp 体系——官方回执没有大章，类别以文字字段呈现）、W-xxxx 单号格式、LCD「探针 · PROBES」计数、假进度百分比（原版 SENDING 显示 `SENDING · P.01 · nn%` 的百分比来自假进度，不是真实进度）。
4. **判定句**：机器元素（`.fx`）内外不得有任何原版 index.html 渲染树里没有的可见物。导航（返回按钮）与档案抽屉必须放在机器区块之外，样式走区块标题口径。

## 五、适配阶段的规则（在纯复刻底版上接后端时适用）

1. **结构冻结**：`.fx` 的 DOM 形状（元素类型/嵌套/数量）与几何（580×784）以纯复刻态为基准；允许的只有——文本节点换字、`input` 换 `select`（纸面字段位，最多两处）、LCD/回执的**文字内容**随真实数据填充。
2. **时间轴不因后端改写**：摘机 650/拨号 950/接通 750/传送 3200 等官方常量保持；传送段若需等待真实响应，只允许「延长」，不允许改动前段节奏与音效编排。
3. **适配新增的可见物**（如纸面下拉）必须用原版纸面字段样式，出现前先截图对照纯复刻态；每轮改完跑「结构断言 + 几何断言 + 像素对照」三件套，差异只能出现在被换内容的文本区域。
4. **弹性链基准纪律（第 19 轮教训）**：浮窗机器内部的弹性盒链（cage→paper→sheet→body→report/paramcard）的「吸收环」必须 `flex: 1 1 0`（基准归零），单面固定行（纸头/字段/章/minfo/privacy）必须 `flex: none`——**禁止 flex-basis:auto**：auto 让内容高度参与基准分配，任何内容增减（如历史块开关）都会沿链传导、压缩变形所有兄弟行（第 19 轮前的「页面高度跳变」根因）。
5. **双线系纪律（第 18 轮教训）**：纸面格线（.fx-body::before 的信纸横线）在独立浮窗中已退役——它糊在纸面不随内容滚，与行级虚线叠加即「线穿字」。行级分隔线只允许来自行样式自身（随内容滚动）。

## 四、争议处理流程（SOP）

1. 先查本文第二节清单——是官方的吗？有出处就是官方。
2. 不在清单里 → grep 原版 index.html（DOM 层，不是 CSS 层）。
3. DOM 有 → 行为对不对再对 fx-fax.js 常量；DOM 无 → 就是自创，删。
4. 拿不准 → 同视口双页截图，逐像素比对，截图说了算。
5. 改完必须留三样东西：改动前后的截图、量取数字、本文件的更新（如发现新的「官方真有/官方没有」条目，随案补录）。
